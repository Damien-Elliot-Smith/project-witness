# Reviewer Note

This package is intended to be handed to a reviewer as a candidate baseline.

Recommended reviewer flow:

1. Verify this candidate package.
2. Extract the runnable local demo pack.
3. Run the local demo pack verifier.
4. Read the limitations and reports.
5. Try to break the candidate.
6. Record findings without assuming failure means the idea is worthless.

The project uses provenance, checksums, deterministic verification, and explicit limits.

It does not claim to solve truth generally.
