# Claims and Limits

## Correct claims

You may say:

```text
Project Witness has a Local v1 Candidate frozen through Move 50.
The candidate includes a runnable/reviewable local demo pack and checksum registry.
Moves 51–70 remain future work.
```

## Incorrect claims

Do not say:

- Project Witness proves truth.
- Project Witness verifies external reality.
- Project Witness proves source trust.
- Project Witness is production-ready.
- Project Witness is signed.
- Project Witness is externally anchored.
- Project Witness final Local v1 Release has been frozen.
- The 70-step roadmap is complete.
- Move 51 has been performed.

## Honest interpretation

This is a candidate suitable for review, testing, and attempted breakage.

It is not a final public release.
